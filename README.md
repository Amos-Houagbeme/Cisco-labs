# Cisco Labs — Packet Tracer

Labs de simulation réseau réalisés avec Cisco Packet Tracer dans le cadre de ma formation en Systèmes, Réseaux & Cloud.

---

## Labs

### [01 — Fondations TCP/IP : routage, DHCP, DNS](01-routage-dhcp-dns/)

Mise en place d'une architecture réseau de base : adressage IP, routage inter-réseaux, déploiement des services DHCP et DNS. Introduction au modèle OSI par la pratique.

**Notions clés :** routes connectées, passerelle par défaut, DORA DHCP, résolution DNS

---

### [02 — Réseau d'entreprise multi-sites : VLANs, WAN, SSH](02-reseau-entreprise-vlan/)

Infrastructure réseau d'entreprise complète avec segmentation par VLANs, routage inter-VLAN (Router-on-a-Stick), interconnexion WAN entre deux sites distants et administration sécurisée via SSH.

**Notions clés :** VLAN, trunk 802.1Q, Router-on-a-Stick, route par défaut, SSH
